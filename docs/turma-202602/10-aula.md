# 10. Busca Ativa — Meio de Semestre

!!! info "Nesta aula"
    - Segundo encontro de **Busca Ativa** do semestre: acompanhamento no
      meio do curso.
    - Autoavaliação de conteúdo (lógica, álgebra booleana, circuitos).
    - Espaço para reforço antes de seguirmos para grafos e árvores.

## 🎯 Por que Busca Ativa de novo, e por que agora

Estamos no meio do semestre. Este é o segundo ponto de checagem: alunos que
ficaram para trás em conteúdo ainda têm tempo de se recuperar **antes** de
seguirmos para os próximos temas — quanto mais cedo uma lacuna é identificada,
mais fácil ela é resolvida.

!!! note "Diferença para a Busca Ativa da Aula 02"
    Na [Aula 02](02-aula.md) o foco era **onboarding** (ferramentas, acesso,
    dúvidas de ementa). Aqui o foco é **conteúdo**: quem está dominando
    lógica, álgebra booleana e circuitos até aqui.

## 🗓️ Como esta aula funciona

=== "👩‍🏫 O professor"
    - Revisa o desempenho nas atividades práticas para identificar quem está
      com dificuldade.
    - Conversa individualmente com alunos identificados, oferecendo reforço.
    - Esclarece dúvidas de conteúdo acumuladas desde a [Aula 03](03-aula.md).

=== "🧑‍🎓 Você"
    - Faça a **autoavaliação de conteúdo** abaixo, com honestidade.
    - Se identificar uma lacuna, **não espere** para resolver — use esta
      aula e a [próxima aula de prática](11-aula.md).
    - Se conhece um colega que está com dificuldade ou sumindo das aulas,
      avise-o sobre este encontro.

## ✅ Autoavaliação — o que você já deveria dominar

!!! check "Marque o que você consegue fazer sem consultar a aula"
    - [ ] Explicar o que é uma proposição e dar um exemplo que **não** é.
    - [ ] Montar a tabela-verdade de $\neg$, $\wedge$, $\vee$, $\to$,
      $\leftrightarrow$ de memória.
    - [ ] Classificar uma fórmula como tautologia, contradição ou
      contingência.
    - [ ] Simplificar uma expressão booleana simples usando os axiomas
      ([Aula 06](06-aula.md)).
    - [ ] Simplificar a mesma expressão com um mapa de Karnaugh
      ([Aula 07](07-aula.md)).
    - [ ] Explicar por que NAND é uma porta universal.
    - [ ] Montar a tabela-verdade de um meio somador ([Aula 09](09-aula.md)).

Se **algum item** ficou sem marcar, volte à aula correspondente **antes** da
próxima aula de atividades — não deixe a lacuna se acumular.

!!! tip "Uso produtivo desta aula"
    Se você está em dia, aproveite a disponibilidade do professor em sala
    para aprofundar dúvidas específicas ou revisar exercícios mais
    desafiadores das aulas anteriores.
